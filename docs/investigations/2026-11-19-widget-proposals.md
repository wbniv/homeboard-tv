# Seven widget implementation proposals

[Open the visual review index](2026-11-19-widget-proposals/index.html).

- [Household noticeboard](2026-11-19-household-noticeboard-widget.md) — recommended 3×2; First: useful offline, no external service.
- [Tasks and chores](2026-11-19-tasks-and-chores-widget.md) — recommended 3×2; Second local-data widget; share editing infrastructure with Notes, not their records.
- [Personal agenda](2026-11-19-personal-agenda-widget.md) — recommended 4×2; Larger integration: extend the shared Calendar repository; offer a separate agenda presentation.
- [Temperature and comfort](2026-11-19-temperature-and-comfort-widget.md) — recommended 3×2; After local widgets: share weather location and request caching with Rain.
- [Commute and transit](2026-11-19-commute-and-transit-widget.md) — recommended 3×1; Data-access spike first; implementation waits for a usable local source.
- [Countdowns and timers](2026-11-19-countdowns-and-timers-widget.md) — recommended 2×1; Selected next: cooking timers and one-off household alarms, sounding across apps; [implementation plan](../plans/2026-11-19-cooking-timers.md).
- [Energy and solar](2026-11-19-energy-and-solar-widget.md) — recommended 4×2; Optional integration only when real household data is available.

Each proposal includes an embedded size/full-screen/phone mockup and workflow
diagram, browser previews, domain-specific data rules, implementation stages and
container/browser/physical screenshot acceptance. All values are illustrative.
The proposals do not change the current default dashboard.

[Preview verification](2026-11-19-widget-proposals/preview-verification.json):
all seven desktop/phone mockups and rendered proposals were checked in the browser
container. These are design previews, not implemented-widget/device evidence.
