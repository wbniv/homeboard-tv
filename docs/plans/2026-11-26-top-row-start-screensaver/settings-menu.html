Why page 1, left

Android's Settings is not a tile in the app grid, so after the gear goes this is its only on-screen route. Left of the hub on page 1 is one key from opening the menu. Home behavior, changed rarely, moves to page 2 (decision D2).

Newer layout

Today Home settings shows only a notice when the dashboard was saved by a newer Homeboard. Proposed: it opens a short menu with Device settings and About Homeboard TV, so Android's Settings stays reachable.
