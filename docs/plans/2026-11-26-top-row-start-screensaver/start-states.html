Start screensaver: what plays, and the other states

OK on Start screensaver runs exactly the remote's screensaver action, so what plays follows the chosen screensaver. Any key ends it and returns to Home with Start screensaver focused.

1 · Focused on Home

Two buttons right of the world clock. The world clock grows into the freed space. Spoken description: "Start screensaver".

2 · Homeboard's Clock chosen

20:22THURSDAY 26 NOVEMBER
Show now
A Homeboard entry plays at once (ScreensaverActivity, mode now). Log: screensaver started mode=now entry=clock.

3 · Home background chosen

Home's background, full screen
Show now
Same path as the Clock: the other built-in entry.

4 · WF Clocks chosen (has a preview screen)

WF Clocks' own preview screen
the clock the app's settings chose
App screen
Stage 5: the app's preview screen in Homeboard's task. A ringing timer closes it and opens the timer screen. Back ends it.

5 · Android app without a preview screen

Android's own screensaver
or Homeboard's Clock where the TV has no start-now
Android
Chosen through Use everywhere. Android starts it when the TV offers start-now; otherwise Homeboard plays its default Clock.

6 · The app's screen will not open

20:22
Couldn't open that action
Uninstalled, disabled or refused: Homeboard plays its own default Clock instead and never crashes (Stage 5 fallbacks). The toast shows only if that also fails.

7 · All Apps

The same two buttons on every All Apps page; Homeboard settings focused here.
