Home settings · Home button

On, one-time setup needed (Google TV)
Home button opens HomeboardOnOffSetup needed

Homeboard needs permission to turn its Home button helper on. Either turn it on yourself in Android's accessibility settings, or run the one-time setup command once from a computer connected to this TV. It is the same command the screensaver's Use everywhere asks for:

adb shell pm grant net.biohack.homeboard android.permission.WRITE_SECURE_SETTINGS There, choose “Home button” and turn it on. If it is greyed out or says “Restricted setting”, Android is blocking it for apps installed from outside Google Play: use the setup command instead. Until then, Home opens Google TV Home as before.

The helper is an Android accessibility service. It sees remote button presses and which app is in front so it can catch Home. It reads nothing on screen and sends nothing anywhere.

Not needed (a TV where Homeboard already is Home)

Home already opens Homeboard

Android uses Homeboard as this TV's Home app, and no other launcher overrides it, so nothing more is needed.

No switch is shown here. If the setting was on from before, its switch stays visible so it can be turned off.
Chooser (a TV where Android asks which app is Home)

Make Homeboard the Home app

Android does not have one Home app on this TV yet. Choose Homeboard as the Home app; no helper is needed.

Off, on a TV that honours the role

The Off state adds: “On this TV Android lets you choose the Home app, which needs no helper. If Home still opens the TV's launcher afterwards, turn the setting above on.” with the same button.

One “what does Home open” screen replaces the old “Default Home app” entry. The role button appears only where no launcher outranks the role.
