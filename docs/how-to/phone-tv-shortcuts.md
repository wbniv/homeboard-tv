# Phone home-screen shortcuts

Connect to a TV using Configure from phone. In the controller, open the TV-name
menu and select **Add TV to home screen**. Give its icon a recognizable name,
such as Cast1 or Cast2, then use your browser's own action:

- Android Chrome: menu → Install and create shortcut → Create shortcut → Add.
- iPhone Safari: Share → Add to Home Screen → Add.

Repeat for each TV. Each entry keeps that TV's identity and your chosen icon
name. It contains no invitation, editing token or permanent approval.

Later, open Configure from phone on the chosen TV, tap its phone icon, and approve
the connection on that TV. Homeboard's phone listener runs only during the
foreground editing session. If the TV's IP address changes, scan its current QR
code and recreate the shortcut. A shortcut for another TV cannot approve editing
on this one.

Browser actions: [Chrome Help](https://support.google.com/chrome/answer/15085120?co=GENIE.Platform%3DAndroid&hl=en-gb),
[Safari User Guide](https://support.apple.com/guide/iphone/bookmark-a-website-iph42ab2f3a7/ios).
